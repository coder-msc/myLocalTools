# DevToolbox · 本地工具箱

一个纯本地运行的开发效率工具箱：接口调试、JSON 处理、本地音乐/视频媒体库、桌面宠物等，开箱即用。
前端为原生 HTML/CSS/JS（无构建步骤、无第三方依赖），后端为 Python 标准库 HTTP 服务，数据全部保存在本地。

## 功能一览

| 模块 | 说明 |
| --- | --- |
| JSON 解析 | 格式化、压缩、树形折叠浏览、路径复制 |
| 异步任务查询 | 轮询任务接口，自动追踪状态与结果 |
| 接口测试 | GET/POST 等请求调试，自定义请求头、请求体，支持保存常用请求 |
| WebSocket | 在线连接调试，消息收发记录 |
| 开发者工具 | 标准/程序员计算器、进制转换、URL/Base64/Unicode 编解码、JSON Diff（结构/文本双模式）、正则测试 |
| 书签管理 | 网址书签分组、拖拽排序 |
| 番茄钟 | 专注计时与统计 |
| 剪贴板 | 剪贴板历史记录（文本/图片） |
| 滚动提醒 | 弹幕式滚动提醒事项 |
| 公共频道 | 局域网内的简易留言板 |
| 本地音乐 | 扫描本地目录，ID3/FLAC 封面与歌词提取、列表循环/单曲/随机 |
| 本地视频 | B 站式观看页（左播放器 + 右侧常驻播放列表）、关键帧封面智能选取、弹幕发送/导入、倍速/画中画/全屏 |

### 媒体库特色

- **目录绑定分类**：为扫描目录指定分类，扫描进来的文件自动归类；改动绑定会同步归类（手动设置的分类不受影响）
- **稳定关联**：文件移动/改名后凭「文件名 + 大小」找回封面、弹幕、标签等数据
- 视频封面在 10%/32%/55%/78% 时长处采样，按细节/变化/亮度评分选取最具代表性的一帧
- 音乐/视频均支持 HTTP Range 拖动播放，封面、弹幕、标签、简介数据持久化

### 桌面宠物（pet.py）

基于 tkinter 的桌面精灵，独立于网页运行：

- 帧动画形象（待机/走路/拖拽/下落/睡觉）
- 鼠标中键按下触发屏幕截图，拖拽选区、松开左键确认
- 置顶且不抢焦点，可拖动、互动

## 技术栈

- **前端**：原生 HTML + CSS + JavaScript（全站 flex 布局，零依赖、零构建）
- **服务端**：Python 3 标准库（`http.server`），单文件 [server.py](server.py)，支持流式 Range 请求
- **桌面宠物**：Python 3 + tkinter（[pet.py](pet.py)），Windows 全局鼠标钩子（`WH_MOUSE_LL`）

## 快速开始

### 网页工具箱

需要 Python 3（无需安装任何第三方包）：

```bat
:: Windows 双击
启动服务器.bat
```

或手动启动：

```bash
python server.py
```

然后浏览器打开 <http://localhost:6868/> 。同一局域网的设备用本机 IP 替换 localhost 即可访问。

### 桌面宠物

```bat
:: Windows 双击
启动宠物.bat
```

或 `python pet.py`。

## 数据与隐私

- 所有数据保存在本地，服务端不向任何外部地址发送请求
- 个人数据（书签、聊天、剪贴板、番茄钟、媒体库等）保存在程序目录下的 JSON 文件与 `media_data/` 中，**已通过 .gitignore 排除，不会进入版本库**
- 首次运行会自动创建默认数据文件；`media_data/`（库数据、封面、弹幕）缺失时自动重建
- 媒体文件仅通过本地 HTTP 服务流式读取，不会被复制或上传

## 项目结构

```
index.html      页面结构与样式、各工具模块
media.js        本地音乐/视频媒体库逻辑
media.css       媒体库样式
server.py       本地 HTTP 服务（API + 媒体流 + 静态文件）
pet.py          桌面宠物
启动服务器.bat   Windows 一键启动服务
启动宠物.bat     Windows 一键启动宠物
```

## 说明

- 本地视频支持浏览器可直接播放的格式（mp4/mov/webm/m4v），mkv/avi 等会提示外部打开
- 扫描目录不允许选择盘根目录，会递归跳过隐藏目录
